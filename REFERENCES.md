# References

Literature behind the hybrid pre-Wannierization added in wien2wannier 3.0.
Source comments and the guides in `doc/hybrid/` cite these entries by the key
in square brackets. The entries are taken from the bibliography of the paper
this release accompanies.

## This work

- **[Comaskey2026]** W. P. Comaskey and J. L. Mendoza-Cortes, "Fully Automated Wannier Disentanglement via Projectability Selection in Gaussian and Augmented Plane-Wave Frameworks," to be published (2026). Cite this paper and the archived release (`CITATION.cff`) when you use the hybrid pre-Wannierization, in addition to [Kunes2010], which every use of wien2wannier must cite.

## Where each reference is used

| Source | What it implements | Keys |
|---|---|---|
| `SRC_w2w/main.F`, `modules_rc.F`, `util_w2w.F` | The wien2wannier interface: projections, overlaps and eigenvalues from WIEN2k vectors; the HYBR mode | Kunes2010, Blaha2020, Comaskey2026 |
| `SRC_w2w/hybrid_prep.F` | b-vector weights, projectability masks, band pool, frozen ceiling, thresholds, pocket rule | Marzari1997, Qiao2023, Lowdin1950, Comaskey2026 |
| `SRC_w2w/hybrid_core.F` | Frozen-constrained spread minimization by the Gauss-Seidel sweep, over-relaxation and Anderson acceleration, rotation to the projected-Hamiltonian eigenbasis, SCDM and Löwdin gauges, gauge transport | Marzari1997, Souza2001, Frankel1950, Young1954, Anderson1965, Walker2011, Damle2015, Damle2017, Damle2018, Green1952, Schoenemann1966, Lowdin1950 |
| `SRC_w2w/hybrid_grass.F` | The same minimization by conjugate gradients on the product of Grassmannians (default) | DamleLevittLin2019, Souza2001, Marzari1997 |
| `SRC_w2w/hybrid_io.F`, `hybrid_files.F` | Wannier90 file formats, hand-off acceptance, subspace continuity | Mostofi2008, Pizzi2020 |
| `tools/band_compare.py` | Band distance against the WIEN2k band path | Vitale2020 |
| `doc/hybrid/05-worked-example.md` | Two-stage wannierization with the Stengel–Spaldin functional | StengelSpaldin2006 |
